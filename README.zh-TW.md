# Tiglet

[English](README.md) | **繁體中文**

一組乾淨、免登入的瀏覽器小工具——同時也是一件個人作品集。
以 Astro + React islands + Tailwind CSS v4 打造，部署於 Vercel。

> 🔗 **線上展示：** [tiglet.vercel.app](https://tiglet.vercel.app)

幾乎所有功能都完全在你的瀏覽器裡執行。沒有帳號、沒有 cookie、沒有廣告——
你的輸入不會離開你的裝置。（例外：少數工具會抓取匯率、發票開獎號碼等公開資料，
以及匿名的頁面瀏覽統計；詳見[隱私](#隱私)。）

## 特色

- **雙語介面**——完整的繁體中文與英文版（`/` 與 `/en/`），一鍵切換、hreflang 互相標注
- **⌘K 命令面板**——在任何頁面快速跳到任何工具
- **淺色／深色模式**——溫暖低對比的主題，一鍵切換（載入不閃爍）
- **最愛與最近使用**——釘選常用工具，顯示在首頁
- **一鍵複製**——每個結果都有複製按鈕
- **可分享的深連結**——工具狀態存在網址裡（例如輪盤的選項）
- **有趣且無障礙的動畫**——骰子 3D 翻滾、輪盤減速、計時環倒數、
  抽獎跑馬燈、2048 方塊彈出；全部尊重 `prefers-reduced-motion`
- **SEO 就緒**——canonical 網址、每個工具中英各一張的 Open Graph 分享卡（66+ 張預先生成的 PNG）、JSON-LD、自動生成 sitemap
- **可安裝的 PWA**——加到主畫面、離線也能用，還能把路線檔直接「分享到」賽段剖面圖開啟

## 技術棧

- **[Astro](https://astro.build)**——靜態輸出，首頁近乎零 JS
- **React**——每個工具一個互動島嶼，延遲 hydrate（`client:visible` / `client:idle`）
- **Tailwind CSS v4**——透過 `@tailwindcss/vite` 管理設計 token
- **Vitest**——每個工具的核心邏輯都有單元測試（550+ 條）
- **Playwright**——65 條 E2E 測試（深連結、檔案上傳、⌘K 面板、雙語、雲端函式工具的 stub 測試），在 CI 執行
- **[@astrojs/sitemap](https://docs.astro.build/en/guides/integrations-guide/sitemap/)**——建置時生成 sitemap
- **[@vite-pwa/astro](https://vite-pwa-org.netlify.app)**——manifest + service worker
- **Web 平台 API**——圖片/色彩工具用 Canvas、密碼生成用 Web Crypto、時區用 `Intl`
- 前端 **SheetJS**（`xlsx`）、**`qrcode`**／**`jsqr`**、**`pdf-lib`** 與 **`marked` + `DOMPurify`**（Markdown 預覽），皆按工具載入

## 開始使用

```bash
npm install      # 安裝依賴
npm run dev      # 啟動開發伺服器
npm test         # 執行單元測試
npm run test:e2e # 執行 Playwright E2E（會建置並預覽網站）
npm run build    # 建置靜態輸出到 dist/
npm run preview  # 預覽正式建置
```

每次推送到 master 與每個 pull request 都會在 GitHub Actions 執行單元測試、
正式建置與 E2E 測試（`.github/workflows/ci.yml`）。

需要 Node 22.12+。

## 專案結構

```
src/
├─ data/tools.ts        # 工具註冊表——首頁與搜尋的唯一資料來源
├─ lib/                 # 純邏輯、有單元測試（每個工具引擎一個模組）
│  └─ __tests__/        # Vitest 測試
├─ components/          # 共用 UI（Header、SearchBar、CommandPalette、CopyButton、Tabs…）
├─ tools/               # 每個工具一個 React 島嶼（只放 UI）
├─ pages/
│  ├─ index.astro       # 首頁啟動器
│  └─ tools/            # 每個工具一頁
├─ layouts/BaseLayout.astro   # 共用 <head>：SEO meta、JSON-LD、主題腳本
└─ styles/global.css    # Tailwind + 設計 token（含深色覆寫與動畫）
```

核心原則是**邏輯與 UI 嚴格分離**：每個工具的行為都放在 `src/lib/` 的純模組裡
（容易獨立測試），`src/tools/` 只放 React 呈現層。首頁、搜尋、命令面板
全部由 `src/data/tools.ts` 這個單一註冊表驅動。

部分工具用分頁**整合**以保持首頁精簡——例如換算器（單位＋匯率）、
生活計算（BMI／百分比／折扣／小費）、圖片工具（壓縮／縮放／轉檔）——
共用同一個 `Tabs` 元件。

## 新增工具

1. 在 `src/data/tools.ts` 加一筆（`status: 'available'`，中英文的
   `titleEn`／`descriptionEn` 都要填）。
2. 核心邏輯放 `src/lib/<tool>.ts`，測試放 `src/lib/__tests__/`。
3. UI 島嶼寫在 `src/tools/<Tool>.tsx`——接受選填的 `locale` prop，
   使用者可見字串放進同檔的 `L = { zh, en }` 字典。
4. 建立中文頁 `src/pages/tools/<tool>.astro` 與英文頁
   `src/pages/en/tools/<tool>.astro`（島嶼傳 `locale="en"`），
   並把 `toolId` 傳給 `BaseLayout` 以記錄「最近使用」。

## 部署

網站是靜態 Astro 建置，零設定部署到 **Vercel**——匯入 repository 後
Vercel 自動偵測 Astro。`vercel.json` 固定建置指令與輸出目錄，
`.npmrc` 確保安裝可重現。

所有頁面皆為預先渲染，沒有 SSR adapter。唯一的例外是 `api/`——
一個獨立的 Vercel 雲端函式目錄，Vercel 會在靜態輸出之外一併編譯它。
目前有三支：`fetch-meta`（網址健檢的 HTML 抓取代理，含 SSRF 防護）、
`invoice-numbers`（轉發財政部統一發票開獎號碼）、`fuel-price`（轉發中油公開牌價）。
這裡的函式必須維持無狀態——不接資料庫、不記錄使用者輸入——而且每次動到
`api/` 都會在真實部署上驗證過才算完成。

## 隱私

Tiglet 幾乎完全在前端運作——無登入、無 cookie、無廣告。抽獎的 Excel 匯入、
QR 產生與掃描、圖片與 PDF 工具、圖片取色，以及其他所有工具，都在你的瀏覽器本機
處理資料，不會上傳任何東西。

少數例外都是「無狀態」的——你送出的內容一律不儲存：

- **換算器**向 [open.er-api.com](https://open.er-api.com) 抓取公開匯率。
  不會送出任何使用者輸入——只是下載最新匯率表。
- **網址健檢**會把你輸入的網址送到一支無狀態的雲端函式（`/api/fetch-meta`），
  由它抓取該頁 HTML 回傳給瀏覽器分析。函式不儲存任何資料、不記錄網址，
  並會拒絕內網／保留位址（SSRF 防護）。
- **發票對獎**與**中油油價**透過無狀態轉發函式抓取官方公開資料
  （財政部開獎號碼、中油牌價）。你的發票號碼在本機比對，不會送到任何地方。
- **Vercel Web Analytics** 匿名、無 cookie 的頁面瀏覽統計
  （無個資、無跨站追蹤，你輸入的任何內容都不會被送出）。
